Welcome to the wiki for **SWE1R Import/Export**, the Blender add-on for making custom tracks, pods and props for *Star Wars Episode I: Racer*.

Every panel in the add-on's sidebar has a **?** button in its header that opens its page here.

## Start here
- [Getting Started](Getting-Started): install the add-on, find the game files, and import and export a first model

## The sidebar, panel by panel
- [Import](Import): bring a model from the game into Blender
- [Export](Export): write a model collection back into the game
- [Tools](Tools): create new models and export the material asset library
  - [Display](Display): show, hide and select visual and collision meshes
- **Mesh**
  - [Visuals](Visuals): how a mesh is drawn in game
    - [Vertex Colors](Vertex-Colors): bake lighting into vertex colors
    - [Materials](Materials): texture, color, transparency, scroll, mirror and clip
      - [Flipbooks](Flipbooks): animate a material's texture through frames
  - [Collision](Collision): what pods collide with
    - [Surface Flags](Surface-Flags): what each surface does to a pod
    - [Fog and Skybox](Fog-and-Skybox): fog, draw distance and the skybox
    - [Pod Lighting](Pod-Lighting): how the pod is lit on a surface
    - [Load Zones](Load-Zones): loading and unloading parts of the track
- [Triggers](Triggers): event triggers
- [Splines](Splines): the racing line
- [Lights](Lights): light streaks
